# 💊 MedCycle — Healthcare & Medicine Sharing App

MedCycle is an Android-based healthcare application designed to make medicine sharing, healthcare assistance, and emergency support more accessible.

The platform connects users through a medicine marketplace, real-time communication, location-based services, and emergency assistance features.

## 🚀 Features

- **User Authentication** — Login, registration, Google Sign-In, and phone OTP authentication.
- **Medicine Marketplace** — Browse, search, sell, and donate medicines.
- **Donate Medicine** — Upload medicine details and images.
- **Real-Time Chat** — Communicate with other users with read receipts and typing indicators.
- **Emergency SOS** — Send emergency alerts with location information and quick-call support.
- **Google Maps Integration** — Location services and nearby assistance.
- **User Profile** — Manage personal information and profile images.
- **Home Dashboard** — Search, medicine categories, and interactive navigation.

## ⚙️ Setup and Installation

For complete installation instructions, Firebase configuration, Google Maps setup, and project requirements, see:

**[SETUP_GUIDE.md](SETUP_GUIDE.md)**

### Prerequisites

- Android Studio
- Android SDK (API 24 or higher)
- JDK compatible with the project Gradle configuration
- Firebase project
- Google Maps API key

### Configuration

Before running the application, configure your own:

- `google-services.json`
- Google Maps API key
- Firebase Authentication and database services
- Any required API credentials

Never commit private API keys, passwords, or service account credentials to the repository.
